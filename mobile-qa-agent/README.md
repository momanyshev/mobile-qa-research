# mobile-qa-agent

Собственный QA-агент этапа 14. Закрепляет **подтверждённые** практики
исследования, а не предположения его начала.

## Что это и чего это не

Агент — это **инструкция плюс контур**, а не отдельная программа. Исполняемая
часть (изоляция данных, seed, oracle, evidence, teardown, метрики) уже
построена и проверена на 41 прогоне — это `../harness`. Агент добавляет к ней
операционный контракт и правила принятия решений.

Строить исполняемую часть заново было бы ошибкой: она проверена selftest'ом из
103 проверок и тремя приложениями.

## Состав

```
mobile-qa-agent/
├── SKILL.md            операционный контракт агента — самодостаточен
├── CONTRACT.md         спецификация входа/выхода и политик (для запускающего)
├── references/
│   ├── README.md       карта к каноническим документам знаний
│   └── sim-use-commands.md
└── evals/              golden evals (подэтап 14.C)
```

Исполняемая часть: `../harness` (CLI прогона, адаптеры, oracle, метрики),
`../docs/knowledge` (руководства), `../docs/runbook.md` (восстановление).

## Запуск одного прогона

Предусловия: поднято ровно одно целевое устройство; для QA Lab — backend на
8888, для Element X — локальный Synapse. UTF-8 локаль обязательна:

```bash
export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8
```

```bash
cd harness
node harness.mjs start --case <caseId> --platform <ios|android> \
     --device <id> --model "<модель>" --skill "mobile-qa-agent@<версия>"
# агент выполняет задание, вызовы — через node sim.mjs --run <runId> -- …
node harness.mjs finish --run <runId> --self-report "…" --knowledge "…"
```

Прерывание: `node harness.mjs abort --run <runId> --reason "…"`.

Метрики серии: `node harness.mjs summary --stage <N>`.

Совместимость с другой версией `sim-use` **не проверялась**: за исследование
инструмент не обновлялся. Процедура проверки при обновлении —
`../docs/knowledge/version-pinning.md`.

## Известные ограничения

Список того, что **не обходится** переформулировкой задания, —
`../docs/knowledge/hard-limits.md`. Кратко: нет звука на симуляторе,
зашифрованное содержимое недоступно oracle, транзиентные состояния недоказуемы
финальным evidence, iOS wheel-picker не отдаёт значение, чистый контекст нельзя
сымитировать инструкцией.

## Статус

Подэтап 14.A (контракт и скелет) — готов. Дальше: 14.B исполняемая часть,
14.C golden evals в чистом контексте, 14.D отложенные измерения, 14.E safety и
повторяемость.

**Автономность агента и экономия времени пока не измерены** — это содержание
14.C–14.D. До их завершения агент не следует представлять как автономный.
